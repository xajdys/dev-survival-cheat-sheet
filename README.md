# Dev Survival Cheat Sheet

A one-page cheat sheet of keyboard shortcuts, terminal commands and developer jargon.
I built it to practice HTML text-level tags.

## What I practiced

| Tag | Used for |
|---|---|
| `<dfn>` | Glossary terms |
| `<kbd>` | Keys to press |
| `<samp>` | Computer output |
| `<var>` | Placeholders you replace |
| `<mark>` | Highlighted key part |
| `<s>` | Older/outdated way |
| `<small>` | Fine print |
| `<time>` | Dates |
| `<data>` | Machine-readable values |
| `<u>` | Commonly misspelled words |
| `<bdi>` / `<bdo>` | Mixed-direction text |
| `<wbr>` | Line-break hints in long URLs |

## Sections

1. Jargon glossary
2. Keyboard shortcuts
3. Terminal commands
4. Community tips

## Run it

No install needed. Download the project and open `index.html` in a browser.

## Built with

HTML and CSS only.
