Glossary & Jargon:

Term Meaning
API A way for two programs to talk to each other
Repository A project folder tracked by Git
Commit A saved snapshot of your code
Terminal A text window where you type commands
Bug A mistake in code that causes the wrong behaviour

Command What it does

mkdir foldername Make a new folder
git status See what changed
git switch -c branchname Make and move to a new branch (newer way)
